# FST Pay — Brand Guidelines

## Brand Identity

**FST Pay** — Fast. Secure. Trusted.

AI-Powered Virtual Wallet + Smart Prepaid Card + Teen Finance Platform

**Tagline**: Spend Smart. Save Smart. Grow Smart.

---

## Color Palette

| Purpose | Hex | Usage |
|---------|-----|-------|
| **Primary** | `#2070FF` | Buttons, links, active states, primary gradients |
| **Secondary** | `#78D3FF` | Accents, secondary actions, lighter gradients |
| **Dark** | `#0E1726` | Dark backgrounds, navbar, sidebar, text |
| **Background** | `#F7FAFF` | Light mode page background |
| **Success** | `#22C55E` | Positive actions, income, savings, confirmations |
| **Warning** | `#F59E0B` | Alerts, streaks, rewards, caution states |
| **Error** | `#EF4444` | Errors, destructive actions, overspend alerts |
| **AI Accent** | `#7C3AED` | AI Coach features, AI-powered badges |
| **Rewards** | `#FBBF24` | Rewards, XP, badges, gamification elements |

## Typography

| Role | Font | Weight | Usage |
|------|------|--------|-------|
| **Logo / Headlines** | Sora | Bold (700) | Logo text, page titles, hero sections |
| **UI / Body** | Inter | 300–700 | Body text, buttons, labels, inputs |
| **Code / Data** | JetBrains Mono | 400–500 | Transaction IDs, card numbers, code |

## Design Language

- **Glass Morphism** — Frosted glass panels with backdrop blur
- **Clay Morphism** — Soft, tactile 3D surfaces with inset shadows
- **Premium Motion** — 60fps animations, micro-interactions, haptic feedback

## Modes

1. **Light Mode** — `#F7FAFF` background
2. **Dark Mode** — `#0E1726` background
3. **AMOLED Dark** — `#000000` background

## Logo

- Icon: FP monogram in brand blue
- Wordmark: "FST Pay" in Sora Bold
- Clear space: Minimum 1x icon width around logo
